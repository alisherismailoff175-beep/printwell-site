## Что это

Статический сайт типографии полного цикла. Прод: https://printwell.uz
УТП: премиум-постпресс (фольгирование, тиснение, Spot UV), ярлыки и бирки.
Клиенты: Chevrolet, Huawei, SQB, Xazna и др.

## Структура

- `public/` — ВЕСЬ сайт, деплоится только эта папка
  - `index.html` — главная (редизайн 2026: hero + marquee + услуги + «О нас»)
  - `about.html, services.html, projects.html, partners.html, request.html, box.html` — внутренние страницы, ещё на старом дизайне
  - `css/styles.css` — скомпилированный Tailwind (НЕ редактировать руками, сборки больше нет), `css/redesign.css` — стили главной
  - `js/redesign.js` — главная: i18n-словарь RU/UZ/EN, анимации, счётчики; `js/app.js` — старые страницы
  - `api/` — serverless-функции Vercel: `chat.js` (AI-чат на Claude API), `lead.js` + `lib/saveLead.js` (заявки → AmoCRM + Telegram + почта), `generate.js`/`image.js` (легаси AI-дизайнера)
  - `vercel.json` — конфиг деплоя
- `docs/` — инструкции менеджерам, `images-to-generate.md` (промпты для AI-картинок)
- `scripts/send-instruction.js` — разовая рассылка PDF в Telegram

## Железные правила

1. Деплой: push в `main` → Vercel автодеплоит на printwell.uz. НИКОГДА не пушить непроверенное.
2. Главная мультиязычная: ЛЮБОЙ новый текст на главной добавляется сразу в 3 языка (ru/uz/en) в словарь `I18N` в `js/redesign.js` + `data-i18n` в разметке. UZ — узбекская латиница.
3. Никаких внешних JS/CSS-библиотек и CDN на главной: чистый CSS + vanilla JS + IntersectionObserver.
4. Не ломать внутренние страницы и `api/` — заявки и AI-чат живые, ими пользуются менеджеры.
5. Анимации обязаны уважать `prefers-reduced-motion` и упрощаться на мобильных (система классов `.reveal`, `data-stagger` — описана в шапке `css/redesign.css`).
6. Картинки: alt везде, `loading="lazy"` у всех кроме hero. Заглушка под будущую AI-картинку — `div.ai-img-placeholder` + комментарий `<!-- AI-IMG: детальный промпт, размер -->`, промпт дублируется в `docs/images-to-generate.md`.
7. Секреты (Claude API, Telegram-токен, AmoCRM) — только в переменных окружения Vercel, в код не вписывать.
8. Коммиты: по одному на логический этап, сообщение по-русски, с префиксом feat/fix/chore/docs.
9. После правок самопроверка: открыть изменённые страницы локально (`start public\index.html`), проверить консоль на ошибки, переключить все 3 языка.
